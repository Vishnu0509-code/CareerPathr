# CareerPathr 🚀

**AI-powered career guidance platform for students**

CareerPathr helps students discover suitable career paths based on their **skills, interests, goals, and assessment results**.

🌐 **Live Demo:** https://career-pathr.vercel.app/

## ✨ Features

* 🎯 Personalized career recommendations
* 📝 Career assessment
* 🧭 Career roadmap generation
* 📚 Course recommendations
* 👤 Student profile management
* 🔐 User authentication
* 📊 Assessment-based career matching
* 🤖 AI-assisted career guidance

## 🛠️ Tech Stack

### Frontend

* React
* TypeScript
* Vite
* CSS

### Backend

* Node.js
* Express
* TypeScript

### Database

* PostgreSQL
* Drizzle ORM

### Deployment

* Vercel — Frontend
* Render — Backend
* Neon — PostgreSQL Database

## 🏗️ Architecture

```text
Student
   ↓
CareerPathr Frontend
   ↓
Vercel
   ↓
CareerPathr API
   ↓
Render
   ↓
PostgreSQL
   ↓
Neon
```

## 🎯 Problem

Students often struggle to understand which career path matches their skills, interests, and long-term goals.

CareerPathr aims to simplify this process by combining assessment results with career information and personalized recommendations.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/Vishnu0509-code/CareerPathr.git
cd CareerPathr
```

### Install dependencies

```bash
pnpm install
```

### Run the project

Configure the required environment variables and start the frontend and backend according to the project configuration.
